## Cómo usar este repositorio

Cada trabajo práctico tiene su propia carpeta, nombrada como `TP X` (por ejemplo, `TP 1`). Dentro de cada carpeta vas a encontrar:

- El informe o documento con las respuestas/desarrollo del TP.
- Cualquier archivo adicional pedido en la consigna (diagramas, capturas de Packet Tracer, etc.).

Para revisar un TP puntual, profe, solo tiene que entrar a la carpeta correspondiente, todo lo relacionado a esa entrega va a estar ahí adentro, sin mezclarse con las demás.
